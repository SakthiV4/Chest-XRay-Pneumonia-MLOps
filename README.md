## Quick Start

### Prerequisites
- Windows 11 / Linux
- NVIDIA GPU with CUDA 12.1 support
- Python 3.11
- Docker Desktop + NVIDIA Container Toolkit
- Node.js 20+

### Phase 1 — Environment Setup

```powershell
# Clone repo
git clone https://github.com/YOUR_USERNAME/Pneumonia-ChestXRay-Pytorch
cd Pneumonia-ChestXRay-Pytorch

# Create & activate virtualenv
python -m venv .venv
.venv\Scripts\Activate.ps1     # Windows PowerShell

# Install PyTorch with CUDA 12.1
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# Install remaining dependencies
pip install -r requirements.txt

# Copy env template
copy .env.example .env     # fill in API keys
```

### Phase 2 — Dataset & Training

```powershell
# Configure Kaggle credentials in .env, then:
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia
Expand-Archive chest-xray-pneumonia.zip -DestinationPath Data/

# Train ResNet-50 (10 epochs, pretrained backbone)
cd training
python main.py --pretrained --endEpoch 10 --batchSize 32

# Export to ONNX
python export_onnx.py
```

### Phase 3 — Backend + Frontend

```powershell
# Start FastAPI backend
cd backend
uvicorn main:app --reload --port 8000

# Start React frontend (separate terminal)
cd frontend
npm install && npm run dev
```

### Phase 5 — Triton + Docker

```powershell
# Start all services (requires NVIDIA Container Toolkit)
docker compose up --build

# Check Triton health
curl http://localhost:8001/v2/health/ready

# Full prediction via API
curl -X POST http://localhost:8000/predict \
     -F "file=@path/to/xray.jpg"
```
